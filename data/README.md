# Veri

`Customer Churn.csv`: UCI Machine Learning Repository'deki **Iranian Churn Dataset**.

- Kaynak: https://archive.ics.uci.edu/dataset/563/iranian+churn+dataset
- Lisans: CC BY 4.0
- 3.150 müşteri, 13 açıklayıcı değişken + hedef değişken (`Churn`)
- Tüm değişkenler ilk 9 ayın toplamıdır; `Churn` 12. ayın sonundaki durumu gösterir (3 aylık planlama boşluğu).
